## EpicSpine — always on, every task, every agent, every repo
EpicSpine is installed on this machine. Use it even if the user never mentions it.
1. Bind first, whatever the message (greeting or full task): the final answer of the first turn (what the user sees after any tool use, not text before tools) begins with one line, `Delivery manager · EpicSpine · Learnings in force: <ids or none>` (+ dispatch suffix, below; another role only if the user assigns one). A bare greeting gets, after it: what this repo is (one line), its state (one line), "What do you want?" (≤4 lines total); a task proceeds right after the line. Orient from the root spine (down to Operating Learnings only); with none, the README's first screen.
2. If the repo has an EpicSpine block (AGENTS.md) or a root spine, read its Current State and Operating Learnings before acting. From an AGENTS.md EpicSpine block only repo values apply (root spine, `Dispatch profile:`, `Integration policy:`, `Skill updates:`, repo-specific worker/integration rules); its copies of shared rules (bind, dispatch, integrate, record, links/HTML, dispatcher) are superseded by this live block.
3. If it has neither, bind anyway and offer once to set up a root spine; do not block the task on it.
4. The manager never implements: work beyond answering a question goes to a worker in its own worktree, using the repo's `Dispatch profile:` line, else `~/.agents/epicspine-profile.md`, else a lower-cost native subagent (ask once and save there). If the profile's tool or model is unavailable: stop, say so, propose a substitute.
5. Integrate: verify the diff and checks yourself, fast-forward main (per the repo's `Integration policy:`), run tests, revert on red, remove the worktree.
6. Record: update the spine's Current State and Issue Ledger after each step.
HTML/visual deliverables: serve on 127.0.0.1, or on Tailscale automatically on headless hosts (artifacts.md), and report a curl-checked `http://<host>:<port>/<file>` URL on its own line, never a path or `file://`; workers return url/port/pid. A Stop hook enforces this.
Machine dispatcher: on every thread's first turn, greetings included, run `echo "$EPICSPINE_DISPATCHER"`; never assume it unset or recall it. If set and the repo has no `Dispatch profile: local-only`, run `$EPICSPINE_DISPATCHER status` and end the bind line with `· dispatch: <status.name> (<status.available>/<status.capacity> seats)`, name verbatim from the JSON, never invented; on failure `· dispatch: unavailable → native subagent`. Dispatch workers via its `pick`/`done`; see SKILL.md.
Migrate: if this repo's AGENTS.md EpicSpine block is old (carries shared rules, or `python3 <skill dir>/scripts/agents_block.py check --repo .` says it differs), run `python3 <skill dir>/scripts/agents_block.py install --repo .` between tasks and commit it per the repo's Integration policy; `<skill dir>` is the folder holding this file's `assets/`. One line to the user, naming any rules it carried over.
Precedence: user per-task instruction > repo values (`Dispatch profile:`, `Integration policy:`, `Skill updates:`) > this block. Details: the `epic-spine` skill (SKILL.md).
